# 校园失物招领（WEB 版）

> 2026 秋软件工程结对作业 · 第二次 · 程序实现
> 结对成员：102401526 林鹏远 / 102401525 丁鑫河

一个面向校园场景的失物招领 Web 应用。用户可以发布**寻物启事**和**招领启事**，集中浏览、按关键词与分类搜索，查看物品详情并联系发布者；物品找回或归还后，发布者可将信息标记为「已找到 / 已归还」，减少重复询问和无效联系。

## 一、技术选型

- **呈现形式**：WEB（移动端 H5 风格页面，在电脑 Chrome 中以手机宽度居中显示）
- **技术栈**：原生 HTML + CSS + JavaScript（**零第三方依赖**）
- **数据存储**：浏览器 `localStorage`（无需后端、无需联网、无需安装）
- **图片处理**：`FileReader` + Canvas 客户端压缩后本地存储

选择纯静态前端的原因：作业要求"下载所有文件后，用谷歌浏览器运行 html 文件就能展现预期结果"，本项目双击 `index.html` 即可完整体验所有功能。

## 三、使用说明

### 1. 运行

**方式一（推荐，符合作业测试方式）**：下载全部文件后，用谷歌浏览器（Chrome）直接双击打开根目录下的 `index.html`。

**方式二（可选）**：在项目根目录启动任意静态服务器，例如：

```bash
# Windows（需已安装 Python）
py -m http.server 8000
# macOS / Linux
python3 -m http.server 8000
```

然后浏览器访问 `http://localhost:8000`。

### 2. 功能与操作路径

| 功能 | 操作方式 |
|---|---|
| 浏览信息 | 首页默认展示全部信息，顶部可按「全部 / 寻物启事 / 招领启事」切换；进行中的信息排在已完结之前 |
| 搜索信息 | 点击首页搜索框或底部「搜索」，输入物品名称 / 地点 / 编号关键词（实时搜索），并可叠加物品分类筛选；无结果时显示空状态，可一键重置或去发布 |
| 发布寻物信息 | 底部「+ 发布」→ 选择「寻物启事」→ 填写名称、分类、丢失地点、丢失时间、描述、联系方式，可选传最多 3 张图片 → 提交 |
| 发布招领信息 | 同上，选择「招领启事」，地点/时间字段自动变为「拾到地点 / 拾到时间」 |
| 查看详情 | 点击任意信息卡片，查看编号、分类、地点、时间、描述、图片与发布者联系方式 |
| 联系发布者 | 详情页可一键复制微信号/手机号；联系方式为手机号时可直接点击「拨打电话」 |
| 更新状态 | 底部「我的」进入我的发布列表，或在详情页（仅发布者本人可见管理区）点击「标记已找到 / 已归还」，确认后完成；支持「撤销完结」 |
| 查看完结结果 | 完结信息在首页列表中置灰并显示「已找到 / 已归还」标签；详情页顶部显示绿色提示横幅，非发布者看到联系方式收起 |

**异常场景处理**：发布表单信息不完整时给出红色行内校验提示；搜索无结果时显示空状态并引导发布；丢失/拾到时间不允许晚于当前时间；已完结信息对非发布者隐藏联系方式，避免无效联系。

### 3. 关于"当前用户"

本应用不做登录注册（作业不要求实名认证）。当前浏览器即视为一名用户：在这台设备上发布的信息会进入「我的发布」。系统预置了 2 条"我发布的"示例信息（一条寻物、一条招领），打开即可体验完整的状态更新流程。

### 4. 恢复示例数据

在浏览器控制台执行 `Store.resetData()` 即可清空你新增的数据并恢复初始示例。

## 四、核心数据结构

一条信息（item）的字段：

| 字段 | 说明 |
|---|---|
| `id` | 唯一标识 |
| `bizNo` | 信息编号，寻物 `XW` / 招领 `ZL` + 日期 + 序号 |
| `type` | `lost`（寻物）/ `found`（招领） |
| `status` | `doing`（进行中：寻找中 / 待认领）/ `done`（已完结：已找到 / 已归还） |
| `name` / `category` / `location` / `happenTime` | 物品名称、分类、地点、发生时间 |
| `description` | 物品描述 |
| `contactName` / `contact` | 联系人、手机/微信号 |
| `images` | 图片 base64 数组（最多 3 张） |
| `createTime` | 发布时间 |

## 五、单元测试

用 Chrome 打开 `test/tests.html` 即可自动运行全部 14 个用例并输出报告（无需安装任何测试框架），覆盖：

- 表单校验：必填项为空、数据完整通过、未来时间拒绝、图片超 3 张拒绝、名称超长拒绝
- 发布：新增信息持久化、编号前缀（XW / ZL）正确、编号序号边界
- 搜索：名称关键词、地点关键词、无结果返回空数组、类型 + 分类组合筛选
- 状态更新：标记「已找到 / 已归还」并持久化、撤销恢复

**用例设计方法**：以白盒测试（分支 / 边界覆盖）为主，针对 `validateItem` 的每个判定分支和 `bizNo` 的序号截断边界逐一设计用例；辅以黑盒测试（等价类划分、错误推测）。测试页面顶部附有完整的测试设计说明与评价。

测试运行结束后会自动恢复示例数据，不影响正常使用。
