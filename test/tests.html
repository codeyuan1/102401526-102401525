测试设计说明
用例设计方法：白盒测试（分支/边界覆盖）为主，黑盒测试（等价类划分、错误推测）为辅。
· 白盒：针对 validateItem 的每个判定分支（空名称 / 超长名称 / 非法分类 / 未来时间 / 图片超限）逐一设计用例，覆盖 bizNo 序号边界（>99 截断分支）；
· 黑盒：按等价类划分搜索输入（命中名称 / 命中地点 / 无命中），按错误推测法覆盖"撤销状态"等易遗漏路径。
评价：14 个用例覆盖核心模块（校验、发布、搜索、状态更新）的全部关键分支与主要等价类，满足本程序的测试要求。
